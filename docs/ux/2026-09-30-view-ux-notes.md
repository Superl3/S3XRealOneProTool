## 화면에서 확인한 사실 (평가 아님)

- 메인 화면은 위에서 아래로 한 열: 상태 pill → EYE 레코더 카드(녹화·사진·마지막 녹화 열기·설정·녹화 보정·연결 해제, 버튼 6개) → 초기 설정(권한·연결·접근성·음성 언어) → 제스처 → 음성 명령 → 삼성 백그라운드 종료 방지 → 미리보기 → 로그.
- 상태 pill과 로그에 포르투갈어 문자열 `[IDLE] Estado atual (sincronizado ao abrir)`가 한국어 UI에 그대로 나왔다. 출처는 `MainActivity.kt:348`의 하드코딩(`strings.xml`에 없음).
- 섹션 제목(`Hm.Eyebrow`)은 11sp에 `marginBottom 10dp`가 붙어 있어, 높이 52dp인 옆 버튼(설정·숨기기·보기)과 세로 중앙이 맞지 않았다.
- 설정 화면은 행마다 요약(설명) 줄이 붙은 한 목록이다. 정적 설명 요약 약 31개, 값 표시 요약(`useSimpleSummaryProvider`) 8개, 코드에서 바뀌는 동적 요약(버튼 배정·조도·머리 보정 상태)이 섞여 있다.

## 사고 기록

- 설정 화면 tooltip을 확인하려고 (200,780)을 1.2초 길게 누른 좌표가 "커서 감도" 슬라이더 위여서 값이 100에서 78로 바뀌었다(`settings-tooltip.png`는 이 상태). 슬라이더를 탭해 100으로 되돌렸고 UI 덤프로 100 확인. 다른 슬라이더(50, 50, 0)는 그대로.
- 접근성 서비스가 "비활성"으로 보인다. 변경 전 상태를 이 세션에서 확인하지 못했고, `adb install -r` 재설치가 원인일 수 있다. 미확정.
- 15:34에 기기가 개발자 옵션 화면이었다(사용자가 폰을 직접 쓰는 중). 이후 기기 입력을 멈췄고, 15:39에 사용자가 폰이 비었다고 알려 재개했다.
