# XREAL Eye Tools 설치 가이드

대상: **XREAL One Pro + Eye**, **Android 14 이상 arm64 휴대폰**, Samsung DeX 사용 환경. 현재 APK는 `0.7.1-eyetools`입니다.

## 휴대폰에 APK 설치

1. [XrealEyeTools-0.7.1-release.apk](../apk/XrealEyeTools-0.7.1-release.apk)를 열고 GitHub 화면의 **Download raw file**로 다운로드합니다. PC에서 받았다면 APK를 휴대폰으로 복사합니다.
2. 휴대폰 **내 파일**에서 APK를 열어 설치합니다. Android가 차단하면 화면에 표시된 안내에 따라 내 파일 또는 사용한 브라우저의 **출처를 알 수 없는 앱 설치**를 허용합니다.
3. XREAL Eye Tools를 엽니다. 카메라 권한을 허용합니다. 알림 권한은 백그라운드 연결·녹화 상태를 보려면 허용하세요. 녹화에 마이크 소리를 넣으려면 마이크 권한도 허용합니다.
4. 손 추적 마우스를 사용한다면 Android 설정의 **접근성 → 설치된 앱 → XREAL Eye Tools**에서 서비스를 켭니다. 안경 영상 촬영만 한다면 이 단계는 생략할 수 있습니다.
5. 안경을 휴대폰에 연결하고 앱의 **연결**을 누릅니다. Android의 USB 사용 허용 창이 나오면 허용합니다. Eye 카메라가 활성화되며 USB 구성이 바뀌면 권한 창이 한 번 더 나올 수 있습니다.

휴대폰에서 앱이 자동으로 열린다면, 화면을 확인한 뒤 **연결**을 눌러도 됩니다. 자동 연결을 원하면 앱 설정에서 켜세요. 자동 연결은 앱이 열린 뒤 **4초 후** 시도하여 휴대폰 화면에 나타나는 USB 권한 창을 볼 시간을 줍니다. 수동 연결 버튼은 이전 권한 요청이 멈춘 경우에도 다시 시도합니다.

## 업데이트와 무선 ADB

같은 파일을 휴대폰에서 다시 설치하면 업데이트됩니다. PC에서 무선 디버깅을 이미 연결했다면 아래 명령도 사용할 수 있습니다. IP와 포트는 **휴대폰의 무선 디버깅 화면에 현재 표시된 값**으로 바꾸세요.

```powershell
adb connect <휴대폰-IP>:<포트>
adb install -r apk\XrealEyeTools-0.7.1-release.apk
```

APK SHA-256: `3743966B804BBA0B942A606293A782322ED876145E59DCB9313861754627C654`

Windows에서 확인:

```powershell
Get-FileHash apk\XrealEyeTools-0.7.1-release.apk -Algorithm SHA256
```

**`INSTALL_FAILED_UPDATE_INCOMPATIBLE`**가 나오면 기존 설치와 서명이 다른 APK입니다. 이 저장소의 APK는 빌드 당시의 로컬 Android 디버그 키로 서명되어 있습니다. 다른 PC에서 직접 빌드한 APK는 서명이 다를 수 있습니다. 기존 앱을 삭제한 뒤 설치하면 앱 설정이 지워지므로, 먼저 필요한 설정과 녹화 파일을 확인하세요.

## 연결 문제 해결

- **안경이 보이지 않음:** 케이블 연결과 휴대폰의 USB 연결 상태를 확인하고 앱의 **연결**을 다시 누릅니다.
- **권한 창을 놓침:** 휴대폰 화면에서 XREAL Eye Tools를 열고 **연결**을 다시 누릅니다. 필요하면 안경을 분리했다가 다시 연결합니다.
- **자동 연결이 너무 빠름:** 자동 연결은 앱이 열린 뒤 4초를 기다립니다. 수동 연결은 언제든 바로 누를 수 있습니다.
- **커서가 움직이지 않음:** 접근성 서비스를 켰는지, 앱에서 손 추적을 켰는지 확인합니다.
- **음성 명령:** 설정에서 한국어 또는 영어 중 하나를 선택합니다. 다른 언어는 지원하지 않습니다.

앱 소스, 기능 설명 및 라이선스는 [저장소 첫 화면](../README.md)에서 볼 수 있습니다. XREAL의 공식 지원 앱은 아닙니다.
